## Story

Come **tech lead quality**,
voglio **aumentare la test coverage di almeno 10 punti percentuali su ogni modulo
`Modules/<Nome>/app`**, misurata con Pest e perimetro dedicato,
così **ogni modulo ha evidenza numerica, test utili (non filler), e il gate coverage
non resta ancorato solo allo scheletro `laravel/app`**.

## Perché (contesto misurazione)

La root `laravel/phpunit.xml` misura solo `app/` (~167 statement) e le `<testsuite>` root
**non eseguono** i 610+ file in `Modules/*/tests/`. Un `./vendor/bin/pest` senza argomenti
non descrive la qualità dei moduli.

`--coverage-filter` da CLI **non sposta il perimetro** (Pest lo ignora — verificato
2026-08-19). L'unico modo corretto è **`Modules/<Mod>/phpunit.xml`** con:

- `bootstrap="../../vendor/autoload.php"` (relativo al file, non alla cwd)
- `<source><include>` → `./app` (e `./src` se esiste)

Moduli con config già presente (2026-08-19): Activity, Job, Media, Rating, User.
Gli altri **14 moduli** devono riceverla come prerequisito wave 0.

## Acceptance Criteria

1. Ogni modulo in `Modules/*/app` (eccetto `TestModule` se vuoto) ha
   `Modules/<Mod>/phpunit.xml` eseguibile da `laravel/`.
2. Baseline coverage registrata in `Modules/<Mod>/docs/testing.md` (o file esistente
   equivalente) con data, comando, % statements, pass/fail count.
3. Dopo implementazione: **delta ≥ +10 punti percentuali** statements rispetto alla baseline
   del modulo (non rispetto alla root).
4. Suite del modulo **verde** (`exit 0`) al momento della misura coverage — Pest non stampa
   il report se ci sono test rossi.
5. Solo **Pest** (`test()`, `it()`, `describe()`); `uses(\Modules\<Mod>\Tests\TestCase::class)`
   per file; helper condivisi via `Modules\Xot\Tests\XotBasePest` (PSR-4, no `require_once`).
6. **Nessuna** cartella `tests/Support/`; nessun `RefreshDatabase` / `migrate:fresh`.
7. `DatabaseTransactions` + MySQL `*_test` (`.env.testing`); skip **condizionato** su
   precondizione ambiente (`moduloDbUnavailable()`), mai skip permanente che nasconde debito.
8. Docs modulo aggiornate: baseline, delta, comandi, file ad alta priorità coperti.
9. Dopo ogni modulo: PHPStan sul modulo verde (`./vendor/bin/phpstan analyse Modules/<Mod>`).

## Comandi canonici (LOCKED)

```bash
# cwd: laravel/

# 1) Baseline / delta coverage modulo
XDEBUG_MODE=coverage ./vendor/bin/pest -c Modules/{Mod}/phpunit.xml \
  --coverage --min=0 2>&1 | tee build/coverage-{Mod}-$(date +%Y%m%d).txt

# 2) Solo test (senza coverage, più veloce)
./vendor/bin/pest -c Modules/{Mod}/phpunit.xml --no-coverage

# 3) Type coverage opzionale (plugin stack 5.17)
./vendor/bin/pest --type-coverage Modules/{Mod}/tests/Unit/SomeTest.php

# 4) Gate statico post-edit
./vendor/bin/phpstan analyse Modules/{Mod} --no-progress --memory-limit=-1
```

Salvare baseline XML per delta automatico:

```bash
XDEBUG_MODE=coverage ./vendor/bin/pest -c Modules/{Mod}/phpunit.xml \
  --coverage --coverage-clover build/clover-{Mod}-baseline.xml --min=0
# ... dopo i test ...
XDEBUG_MODE=coverage ./vendor/bin/pest -c Modules/{Mod}/phpunit.xml \
  --coverage --coverage-clover build/clover-{Mod}.xml --min=0
php -r '
$b=simplexml_load_file("build/clover-{Mod}-baseline.xml")->project->metrics;
$a=simplexml_load_file("build/clover-{Mod}.xml")->project->metrics;
$p=fn($m)=>(int)$m["statements"]?100*(int)$m["coveredstatements"]/(int)$m["statements"]:0.0;
printf("{Mod}: %.2f%% -> %.2f%% (%+.2f)\n",$p($b),$p($a),$p($a)-$p($b));'
```

## Template `phpunit.xml` (wave 0)

Copiare da `Modules/Activity/phpunit.xml` — **non** `vendor/autoload.php` senza `../../`.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<phpunit bootstrap="../../vendor/autoload.php" colors="true">
    <testsuites>
        <testsuite name="Module">
            <directory suffix="Test.php">./tests</directory>
        </testsuite>
    </testsuites>
    <source>
        <include>
            <directory suffix=".php">./app</directory>
        </include>
    </source>
</phpunit>
```

## Strategia test (cosa coprire per +10%)

Priorità per ROI — in ordine:

1. **Actions / Datas / Enums** — logica pura, zero DB, PHPStan-friendly.
2. **Policies** — mock `UserContract`, assert allow/deny.
3. **Filament static API** — `getTableColumns()`, factory `::create()`, **non** ispezionare
   componenti fuori da `Schema` (esplode `$container` non init).
4. **Rules / Cast / Value objects** — input edge cases.
5. **Feature** — solo se MySQL `*_test` raggiungibile; altrimenti skip condizionato.

Anti-pattern vietati:

- Test che assertano chiavi `fix:` (traduzione mancante) invece della label reale.
- `User::factory()` senza narrowing → usare `UserFactory::new()->createOne()` + `assertInstanceOf`.
- Duplicare helper già in `XotBasePest`.

## Dev guardrails

| Regola | Dettaglio |
|--------|-----------|
| Neon | `laravel/phpstan.neon` immutabile agenti |
| Composer root | minimo — dipendenze Pest in `Modules/Xot/composer.json` |
| Remote | dopo modulo verde: `cd Modules/<Mod> && git remote -v` → push **tutti** |
| Coverage min | story 5.2 target globale 82% / 85% — questa story è **per-modulo +10%** |
| DB down | Pest exit 3 = ambiente, non fix codice |

- ADR-017: `pest()->extend()` solo con ignore inline su `Pest.php` se necessario.
- NFR-CQ-002 (PRD): critical paths 100% — moduli User/Rating/Progressioni/Sigma prioritari.
