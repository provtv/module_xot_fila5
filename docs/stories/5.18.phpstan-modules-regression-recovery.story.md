## Dev Guardrails

| Regola | Dettaglio |
|--------|-----------|
| Neon | Solo `laravel/phpstan.neon`; agenti **zero touch** |
| `mixed` | Ultima spiaggia; preferire union + `is_*` |
| Mockery | `@return Mockery\MockInterface&UserContract` per mock con `shouldReceive()` |
| Pest skip | Mai closure vuota — `test('name')->skip('reason')` |
| Composer | Dipendenze Pest/phpstan in `Modules/Xot/composer.json`; root minimo (nwidart merge) |
| Remote | `cd Modules/<Mod> && git remote -v`; fetch/push **tutti** i remote |
| Coverage | +10% sul modulo toccato quando possibile (`-c Modules/<Mod>/phpunit.xml`) |
