# 17.1: PHPStan `analyse Modules` 202 errors fix

**Story ID:** 17.1
**Epic:** 17 — PHPStan Quality Gate Maintenance
**Slug:** phpstan-modules-202-errors-fix
**Status:** in_progress
**Created:** 2026-08-25
**Updated:** 2026-08-25

## Story

Come **tech lead responsabile della qualità su `dev`**,
voglio **`./vendor/bin/phpstan analyse Modules` con zero errori reali**,
cosi' **il gate PHPStan rimane bloccante e non ci sono bug mascherati**.

Stato di partenza: 202 errori totali, cosi' distribuiti:
- **method.notFound**: ~30 errori - metodi mancanti in Lang module e test
- **staticMethod.notFound**: ~15 errori - metodi statici mancanti in TestCase
- **argument.type**: 1 errore - DBAL non-empty-string
- **missingType.iterableValue**: ~10 errori - array senza tipo valore
- **return.unusedType**: ~5 errori - metodi che restituiscono tipo errato
- **trait.unused**: 1 errore - trait non usato
- **deprecated**: ~140 errori - metodi/classi deprecated Filament (NON da fixare ora)

## Acceptance Criteria

1. `cd laravel && ./vendor/bin/phpstan analyse Modules --no-progress` termina con zero errori reali (deprecated accettati).
2. `phpstan.neon` non e' modificato.
3. Nessun errore e' stato spento con `@phpstan-ignore`, `@var` inline, `assert()`, cast di comodo.
4. I metodi mancanti sono implementati nei moduli appropriati (Lang, Xot, etc.).

## Error Categories to Fix

### 1. method.notFound (~30 errori)

#### Lang module - LocaleSwitcherRefresh::applyLocale()
- **Files**: Lang/tests/Unit/Filament/LocaleSwitcherRefreshTest.php, Lang/tests/Unit/LangFinalGapsTest.php
- **Action**: Implementare metodo `applyLocale()` in `Modules\Lang\Filament\Actions\LocaleSwitcherRefresh`

#### Lang module - EditTranslationFile methods
- **Files**: Lang/tests/Unit/LangCoverageGapsTest.php, Lang/tests/Unit/LangFinalGapsTest.php, Lang/tests/Unit/LangHundredPercentCoverageTest.php
- **Methods**: `getFormSchema()`, `schemaFromRecord()`
- **Action**: Implementare metodi mancanti in `EditTranslationFile`

### 2. staticMethod.notFound (~15 errori)

#### Lang TestCase methods
- **Files**: Lang/tests/Unit/LangCoverageBoostTest.php, Lang/tests/Unit/LangCoverageGapsTest.php, Lang/tests/Unit/LangHundredPercentCoverageTest.php, Lang/tests/Unit/LangFinalGapsTest.php
- **Methods**: `createTranslationFile()`, `bindRealSaveTransAction()`, `restoreSaveTransActionNoOp()`, `forceSqliteTranslations()`
- **Action**: Implementare metodi in `Modules\Lang\Tests\TestCase`

### 3. argument.type (1 errore)

#### DBAL non-empty-string
- **File**: DbForge/app/Actions/Model/GetTableIndexesByModelClassAction.php
- **Line**: 25
- **Action**: Aggiungere validazione `Assert::notEmpty()` prima di introspectTableIndexesByUnquotedName

### 4. missingType.iterableValue (~10 errori)

#### Lang module stubs
- **Files**: Lang/tests/Unit/LangCoverageGapsTest.php, Lang/tests/Unit/LangFinalGapsTest.php
- **Action**: Aggiungere `@param array<...>` con tipi specifici ai metodi stub

### 5. return.unusedType (~5 errori)

#### Lang module stubs
- **Files**: Lang/tests/Unit/LangFinalGapsTest.php
- **Action**: Correggere tipo di ritorno dei metodi stub

### 6. trait.unused (1 errore)

#### EnsuresUiDatabaseSchema
- **File**: UI/tests/Support/EnsuresUiDatabaseSchema.php
- **Action**: Rimuovere trait se non usato, oppure usarlo in un test
