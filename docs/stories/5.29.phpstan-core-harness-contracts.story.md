# XOT-5.29 — contratti dei producer coverage canonici

## Story

Come maintainer Xot, voglio tipizzare i producer condivisi prima dei consumer, così che le
story successive ereditino contratti verificabili invece di propagare `mixed`.

## Acceptance Criteria

<!-- LOCKED -->
1. I 15 finding correnti nei cinque file owned sono risolti alla causa radice.
2. Discovery, callback, model e collection boundary restituiscono tipi concreti osservabili.
3. `TestCase` non usa API PHPUnit interne e le utility Safe sono adottate alla fonte.
4. Nessuna suppression, baseline, tautologia o modifica fuori scope.
