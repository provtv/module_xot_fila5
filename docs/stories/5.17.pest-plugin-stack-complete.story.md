## Story

Come **architect toolchain**,
voglio **tutti i plugin Pest richiesti installati e verificati via nwidart merge-plugin**,
così **`laravel/composer.json` resta minimo**, PHPStan riceve le regole Pest automaticamente,
e ogni agente conosce il workflow `composer update -W`.

## Perché (discussione multi-agente)

| Voce | Decisione | Rationale |
|------|-----------|-----------|
| Dipendenze in root? | **No** | nwidart: dev stack in `Modules/Xot/composer.json` |
| `type-coverage` esplicito? | **Sì** | Bundled con Pest ma dichiarato in Xot per intent e lock |
| `extension-installer` | **Sì** | Registra `pestphp/pest/extension.neon` senza edit agenti su `phpstan.neon` |
| Duplicate `includes:` neon | **Fix utente** | ADR-019: agenti non toccano `laravel/phpstan.neon` |
| Activity `PestStubs` | **Rimosso** (story 3.10) | Plugin laravel/livewire ufficiali |

## `laravel/composer.json` — invariante minimo

- **Zero** righe `pestphp/*` in require/require-dev
- `allow-plugins`: `pestphp/pest-plugin`, `phpstan/extension-installer`, merge-plugin
- `merge-plugin.include`: `Modules/*/composer.json`

## Workflow obbligatorio

```bash
cd laravel
composer update -W    # dopo OGNI edit a Modules/*/composer.json
composer show '*phpstan*'
composer show 'pestphp/pest-plugin-*'
```

## Acceptance criteria

1. Tutti e 7 plugin + `extension-installer` + `rector/rector` risolti in vendor via merge Xot.
2. `composer update -W` eseguito senza errori; log `phpstan/extension-installer: Extensions installed`.
3. Verifiche funzionali PASS (vedi sotto).
4. Docs second brain aggiornate: `pest-official-plugins.md`, `pest-plugins-rector-phpstan.md`.
5. Nessuna modifica agenti a `laravel/phpstan.neon`.

## Blocco noto (utente)

PHPStan exit 1 per `includes:` duplicati in `laravel/phpstan.neon` quando `extension-installer`
è attivo. Rimuovere manualmente le righe già gestite dall'installer (larastan, carbon, safe-rule, pest).
